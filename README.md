# Date Planner

Generic date-planning site with:
- September 2026 date selection
- Cafe / Dinner / Cinema
- Place cards with images
- Cafe & Dinner time selection
- Cinema movie selection (no movie times)
- EmailJS submission

## EmailJS
The project is already configured with the EmailJS service, template and public key supplied in the project setup.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the root of the `main` branch.
Then enable GitHub Pages from Settings → Pages → Deploy from a branch → main → / (root).
